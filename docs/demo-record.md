# 2025년 '약장수' 시연 기록

**자료:** 개인이 보관해 둔 Chrome 화면 녹화  
**영상 파일에 기록된 생성 시기:** 2025년 10월 말  
**전체 길이:** 약 66초  
**본 문서 작성:** 2026년 11월

> 영상의 파일 생성 시각이 해커톤 당일 또는 모든 기능의 완성 시각을 뜻하는 것은 아닙니다. 날짜의 정확한 일치보다 **2025년 가을에 실제 실행했던 기록이 남아 있다는 점**을 확인하기 위한 자료입니다.

## 실제 영상에서 관찰한 흐름

| 영상 구간(대략) | 화면에서 보이는 동작 |
| --- | --- |
| 0~30초 | `localhost:3000/home` 의약품 검색 목록 탐색, 카테고리 버튼을 순서대로 클릭해 결과가 달라지는 모습 |
| 30~40초 | `localhost:3000/` 의약품 챗봇 화면으로 이동. 테스트 계정으로 로그인된 UI와 인사말이 표시됨 |
| 40~66초 | 증상 문장을 입력하고 응답이 순차적으로 늘어나는 장면. 여러 문장을 입력해 답변 형태를 확인 |

동영상 화면에는 **'약장수'** 라는 명칭, 검색/상담 화면 전환, 테스트 계정 표시 및 서버에서 보내는 텍스트를 누적 출력하는 UI가 보입니다.

## 이 영상이 증명하는 것과 증명하지 못하는 것

**확인할 수 있는 것:** 2025년 10월 말 무렵 로컬 브라우저에서 화면이 실행됐고, 검색 카테고리 필터와 챗봇 인터페이스의 기본 동작을 시연했다는 사실.

**영상만으로는 알 수 없는 것:** 모든 기능의 정확성, 실제 의료 안전성, LLM API 사용 여부, 로그인 인증의 보안성, 장기 안정성, 서버 배포 여부, 팀원별 코딩 기여도. 이 부분은 저장소 코드를 별도로 검토해야 합니다.
